# Code of Conduct

Be direct about ideas and generous with people.

- Critique the experiment, not the person. "Your baseline is unmatched" is useful;
  "you are careless" is not.
- Negative results are first-class contributions here. Nobody should feel pressure to
  make a hypothesis survive.
- No harassment, no discrimination, no personal attacks.
- If someone points out that your comparison is unfair, thank them and fix it.
  That happened during this project and it improved the result.

Maintainer: Kapil Dhinwa. Report problems via GitHub issues.
